# 1. Descripción del caso

El presente proyecto tiene como objetivo diseñar e implementar la base de datos relacional de un sistema de gestión de ventas para una farmacia, comercio dedicado a la venta de medicamentos (con y sin receta), productos de perfumería, cuidado personal e insumos varios.

El sistema debe soportar el ciclo completo de la operatoria de venta:

- Registro y consulta de clientes.
- Control de stock de productos organizados por lote y fecha de vencimiento.
- Gestión de proveedores.
- Registro de ventas con uno o múltiples métodos de pago.
- Conservación de un historial de precios que no se vea alterado por modificaciones posteriores al catálogo.
